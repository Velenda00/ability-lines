# 2026-07-09 工作日志

## 再塑法典 - 修复思绪标签栏和编辑备选不显示

### 问题
思绪页面标签导航栏（标签+条数，点击筛选）不显示，编辑思绪时已有标签备选也不显示。

### 根因
`Store.getAllTags()` 依赖 `this._allData`：
```js
getAllTags() {
    if (!this._allData) return [];  // 首次进入时为 null，直接返回空
    this._allData.thoughts.forEach(...)
}
```
但页面初始化 `DOMContentLoaded` 调用的是 `Store.init()`，而 `init()` **不设置 `this._allData`**。只有 `Store.getAll()`（由 `refresh()` 调用）才设置。

因此：刚打开应用直接进思绪页（未触发任何操作），`Store._allData` 为 null → `getAllTags()` 返回空 → 标签栏和备选不显示。

### 修复
`store.js` `init()` 两个分支末尾都增加 `this._allData = data/def`：
- 数据存在分支（补字段后）：`this._allData = data;`
- 数据不存在分支（创建默认数据）：`this._allData = def;`

### 验证
- `node -c` 语法校验通过
- 页面预览正常
