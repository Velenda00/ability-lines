# 2026-05-18

## V4.1 多项体验优化

### 1. 行为卡片手机端显示不全修复
- **问题**：专项详情页行为/问题/收获卡片在手机上右侧按钮（✅、待办数量等）被截断
- **原因**：卡片右侧的 badges 和按钮没有包裹在 flex-shrink: 0 的容器里，窄屏下被 flex 压缩
- **修复**：
  - `app.js`：将行为/问题/收获卡片的 badges 和按钮包裹在 `<div class="proj-li-right">` 容器里
  - `css/style.css`：添加 `.proj-li-right { display: flex; align-items: center; gap: 4px; flex-shrink: 0; }`
  - `css/style.css`：`.proj-li` 和 `.proj-ii` 的右侧 padding 从 0 改为 8px

### 2. 思绪备注折叠
- **需求**：备注内容只显示前两行，剩余部分折叠
- **实现**：
  - `app.js` `renderThoughts`：当备注长度超过40字符或包含换行时，使用折叠模式渲染
  - `css/style.css`：添加 `.thought-note-collapsed`（`-webkit-line-clamp: 2`）和 `.thought-note-toggle` 样式
  - `app.js`：添加 `toggleThNote()` 函数切换展开/收起状态

### 3. 思绪标签筛选
- **需求**：思绪区显示所有标签及各标签条数，点击标签只显示该标签内容
- **实现**：
  - `index.html`：搜索框下方添加 `#thoughtTagsBar` 容器
  - `app.js`：新增 `_thoughtTagFilter` 状态变量和 `switchThoughtTagFilter()` 函数
  - `app.js` `renderThoughts`：顶部渲染标签栏（全部 + 各标签及条数），根据 `_thoughtTagFilter` 过滤内容
  - `css/style.css`：添加 `.thought-tags-bar` 和 `.thought-tag-chip` 样式（pill 形状，active 态高亮）

### 4. 解放脑关联思绪数量
- **需求**：解放脑卡片显示关联思绪数量（类似习惯 🔥N）
- **实现**：
  - `app.js` `renderAbility` 解放脑卡片渲染：计算 `appData.thoughts.filter(t => t.relatedLiberationId === e.id).length`
  - 显示为 💭N 徽章，放在习惯徽章旁边
