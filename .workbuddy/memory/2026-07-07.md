# 2026-07-07 工作日志

## 再塑法典 - 修复工作聚焦视图周历条bug

### 问题
点入日期（如 2026-07-07）后，聚焦视图的周历横栏显示的不是包含该日期的行。例如 7月7日 属于 7月6日-12日那周，但横栏显示的是 6月29日-7月5日。

### 根因
`renderWorkFocus` 函数中 `_workWeekStart` 只在第一次为空时计算：
```js
if (!_workWeekStart) _workWeekStart = getMonday(...);
```
一旦 `_workWeekStart` 被设置，之后切换日期进入聚焦视图时周历条不再更新，始终停留在第一次进入的日期所在周。

### 修复
改为每次进入聚焦视图都根据当前 `_workFocusDate` 重新计算周一：
```js
_workWeekStart = getMonday(new Date(_workFocusDate + 'T12:00:00'));
```
