## 再塑法典 - 工作轨问题模块增加"问题内容"字段

在「工作轨」编辑/新增工作事件时，「⚠️ 发现问题」模块最顶部新增「问题内容」字段。

### 修改内容（共7处，涉及 app.js + store.js）
1. **新增模态框** (app.js `showAddWorkEventModal`): 问题模块顶部增加 `wm_pbtext` 字段
2. **新增保存逻辑**: 读取 `wm_pbtext` → `evt.problem.text`
3. **编辑模态框** (app.js `showEditWorkEventModal`): 问题模块顶部增加 `we_pbtext` 字段
4. **编辑填充值**: `sv('we_pbtext', pb.text)`
5. **编辑保存逻辑**: 读取 `we_pbtext` → `updates.problem.text`
6. **卡片渲染** (app.js `renderWorkEventCard`): 问题部分最前显示「问题内容」
7. **导出 Markdown** (store.js `buildWorkExportMd`): 问题部分最前输出「问题内容」
8. **默认数据结构** (store.js `addWorkEvent`): problem 默认值增加 `text:''` 字段

### 数据模型变更
- `problem` 对象: `{ reason, suggestion, value }` → `{ text, reason, suggestion, value }`
- `text` 字段为新增，旧数据无此字段时渲染为空（renderFormText 处理 undefined），向后兼容
