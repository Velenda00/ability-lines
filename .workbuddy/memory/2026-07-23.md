# 2026-07-23 工作日志

## 再塑法典 - 修复工作标签备选不显示新增标签

### 问题
工作中新增标签保存后，编辑下一条工作事件时，备选标签区看不到之前新增的标签。

### 根因
1. `refreshWMHints`/`refreshWEHints` 中 `.slice(0, 5)` 只显示前5个备选标签
2. `_syncWorkTags` 用 `new Set(data.workTags || [])` 收集标签，已有标签在前、新标签追加在后
3. 当已有标签≥5个时，新增的标签排在第6位以后被 slice 截断，看不到

### 修复
**store.js `_syncWorkTags`**：改为先收集当前事件中实际使用的标签（排前面），历史标签（不再使用的）排后面：
```js
const usedTags = new Set();
// 收集事件中的标签...
const historical = (data.workTags || []).filter(t => !usedTags.has(t));
data.workTags = [...usedTags, ...historical];
```

**app.js `refreshWMHints`/`refreshWEHints`**：去掉 `.slice(0, 5)` 限制，显示所有备选标签（CSS 已有 flex-wrap 自动换行）。
